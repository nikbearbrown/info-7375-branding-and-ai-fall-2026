# INFO 7375 — Branding and AI

Public repository: [info-7375-branding-and-ai](https://github.com/nikbearbrown/info-7375-branding-and-ai). The publication includes the course, narrative readings, and available book images. Local framework checkouts, prior course records, research, and production exports are excluded. The older book README describes the broader local workspace; those optional tools are not dependencies of the Fall 2026 course.

**Fall 2026 · Predict → Build It → Use It → Ship It → Verify**

Build one running brand: your professional identity, a fictional venture, or an organization you are authorized to represent. Each lesson adds an inspectable decision and creative artifact, supported by a small Python mechanism. Claude Code helps draft, implement, and critique; the human supplies creative direction, audience judgment, evidence review, and authorization.

Claude Code access through NEU is assumed. Start with [NEU prerequisites](prerequisites/README.md) and [Northeastern's Claude portal](https://claude.northeastern.edu/). Independent readers need their own Claude Code-enabled account. Direct API credits are not required.

The nineteen core chapters become fifteen lessons. Chapters 20–23 are optional product-track reading. The original [book README](README.md), [license](LICENSE.md), manuscript, and media remain intact. Required exercises use Claude Code and Python standard-library implementations; older Madison, web-framework, and multi-provider examples are historical or optional context rather than required dependencies.

Lessons provide build specifications and verification cases; they are not finished reference implementations. Students build the mechanisms and explain their results. Graded work uses the ten-day 100-point model: 60 implementation, 10 Frictional, 10 GitHub posting, 20 Relative Quartile. Lesson Assessments are ungraded. Videos and Brutalist are optional.

Canvas supplies exact dates and official institutional policy text. The course can be completed with local creative specimens, written evidence, and mock campaigns; publication and paid production are separate decisions.

# Lesson 8 — Make every channel carry the same claim

**Predict → Build It → Use It → Ship It → Verify**

Reading: [Chapter 12](../../chapters/12-content-media-and-campaigns.md). See the [reading map](../../docs/reading-map.md) for this semester's adaptations. Tools: Claude Code and Python standard library. Prerequisites: previous lessons and the running brand project. Suggested pacing: one class session plus practice; Canvas controls dates.

## Predict

Which channel adaptation risks changing the meaning of your campaign promise? Record the expectation, assumptions, and a possible falsifier in PREDICTIONS.md before reviewing Claude's output. Preserve the first entry when recording later findings.

## Build It

Build a Python campaign-manifest validator for audience, channel, objective, message, claim evidence, owner, and approval status. Produce a small set of draft channel artifacts. Make an initial attempt before asking for a complete solution. Use learning-artifacts/08-campaign-and-content/ for main.py, test_main.py, inputs, and outputs. The Python check supports the brand decision; it does not make that decision for you.

## Use It

Ask Claude to adapt a single campaign brief for three channels. Label paid, earned, shared, and owned placements as plans, not evidence that coverage or purchases occurred. Record actual prompts, model identifier as displayed, date, commands, and outputs. Label fictional brands, synthetic data, simulated feedback, and mock campaigns. Claude Code is assumed; direct API calls are optional and may consume separate credits.

## Ship It

Deliver campaign brief, manifest, three draft messages, and consistency audit. Add README.md with exact reproduction commands, PREDICTIONS.md, CONTRIBUTIONS.md, FRICTIONAL.md, and VERIFICATION.md from the [templates](../../templates/README.md). Package a local candidate ready for review. The [Assignment map](../../assignments/fall-2026/README.md) specifies final submission.

## Verify

Test missing claim proof and contradictory offers across channels. Verify all dates, prices, and promises in the mock campaign. No ad spend, outreach, or publication is required. Check the packaged candidate rather than only the development copy. Record actual results and unresolved limits. If a check fails, revise, ship, and verify again. Compare the outcome with your prediction.

### Assessments — ungraded

1. Produce the brand artifact and supporting Python mechanism.
2. Run the specified positive and failure cases and explain one result yourself.
3. Identify a case in which the code passes but the brand claim or decision remains unsupported.

## Irreducibly Human

**AI should** adapt messages and inspect consistency.

**Human should** choose the campaign objective, approve actual claims, and authorize any real release.

Record the actual division in CONTRIBUTIONS.md: accepted, changed, rejected, or still uncertain. Do not invent audience feedback, testimonials, approvals, or creative decisions that a person did not make.

# Lesson 13 — Adapt the message without inventing the audience

**Predict → Build It → Use It → Ship It → Verify**

Reading: [Chapter 17](../../chapters/17-global-and-cross-cultural-branding.md). See the [reading map](../../docs/reading-map.md) for this semester's adaptations. Tools: Claude Code and Python standard library. Prerequisites: previous lessons and the running brand project. Suggested pacing: one class session plus practice; Canvas controls dates.

## Predict

Which assumption may fail when the same message reaches a different audience? State the evidence you would need. Record the expectation, assumptions, and a possible falsifier in PREDICTIONS.md before reviewing Claude's output. Preserve the first entry when recording later findings.

## Build It

Build a Python localization matrix for invariant claims, adaptable expressions, audience evidence, language, reviewer, and unresolved questions. Make an initial attempt before asking for a complete solution. Use learning-artifacts/13-cross-cultural-adaptation/ for main.py, test_main.py, inputs, and outputs. The Python check supports the brand decision; it does not make that decision for you.

## Use It

Ask Claude to propose two audience-specific versions of a message. Critique unsupported cultural generalizations and preserve factual claims. If a qualified reviewer participates, record actual feedback; otherwise label review as pending. Record actual prompts, model identifier as displayed, date, commands, and outputs. Label fictional brands, synthetic data, simulated feedback, and mock campaigns. Claude Code is assumed; direct API calls are optional and may consume separate credits.

## Ship It

Deliver adaptation matrix, two drafts, claim comparison, and review limits. Add README.md with exact reproduction commands, PREDICTIONS.md, CONTRIBUTIONS.md, FRICTIONAL.md, and VERIFICATION.md from the [templates](../../templates/README.md). Package a local candidate ready for review. The [Assignment map](../../assignments/fall-2026/README.md) specifies final submission.

## Verify

Test a changed factual promise hidden inside a stylistic adaptation. Language fluency alone does not establish cultural fit. Do not fabricate native-speaker review. Check the packaged candidate rather than only the development copy. Record actual results and unresolved limits. If a check fails, revise, ship, and verify again. Compare the outcome with your prediction.

### Assessments — ungraded

1. Produce the brand artifact and supporting Python mechanism.
2. Run the specified positive and failure cases and explain one result yourself.
3. Identify a case in which the code passes but the brand claim or decision remains unsupported.

## Irreducibly Human

**AI should** generate alternatives and compare meaning.

**Human should** define the audience, seek appropriate feedback, and decide the limits of the adaptation.

Record the actual division in CONTRIBUTIONS.md: accepted, changed, rejected, or still uncertain. Do not invent audience feedback, testimonials, approvals, or creative decisions that a person did not make.

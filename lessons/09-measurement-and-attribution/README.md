# Lesson 9 — A number that moved needs an explanation

**Predict → Build It → Use It → Ship It → Verify**

Reading: [Chapter 13](../../chapters/13-measuring-brand-equity-and-impact.md). See the [reading map](../../docs/reading-map.md) for this semester's adaptations. Tools: Claude Code and Python standard library. Prerequisites: previous lessons and the running brand project. Suggested pacing: one class session plus practice; Canvas controls dates.

## Predict

Will an apparent improvement persist after you check denominators and segment composition? Record the expectation, assumptions, and a possible falsifier in PREDICTIONS.md before reviewing Claude's output. Preserve the first entry when recording later findings.

## Build It

Build Python functions for conversion rates and differences using explicit numerators and denominators. Preserve raw counts, time windows, segments, and synthetic/observed labels. Make an initial attempt before asking for a complete solution. Use learning-artifacts/09-measurement-and-attribution/ for main.py, test_main.py, inputs, and outputs. The Python check supports the brand decision; it does not make that decision for you.

## Use It

Ask Claude to interpret a small synthetic campaign table, then audit its conclusions. Separate brand measures from short-term response measures and observational differences from causal effects. Record actual prompts, model identifier as displayed, date, commands, and outputs. Label fictional brands, synthetic data, simulated feedback, and mock campaigns. Claude Code is assumed; direct API calls are optional and may consume separate credits.

## Ship It

Deliver measurement plan, raw table, calculation code, and interpretation audit. Add README.md with exact reproduction commands, PREDICTIONS.md, CONTRIBUTIONS.md, FRICTIONAL.md, and VERIFICATION.md from the [templates](../../templates/README.md). Package a local candidate ready for review. The [Assignment map](../../assignments/fall-2026/README.md) specifies final submission.

## Verify

Check 10/100 and 15/300: more conversions can coexist with a lower rate. Test zero denominators and counts outside valid ranges. This comparison alone does not establish a campaign effect. Check the packaged candidate rather than only the development copy. Record actual results and unresolved limits. If a check fails, revise, ship, and verify again. Compare the outcome with your prediction.

## Irreducibly Human

**AI should** calculate and propose explanations.

**Human should** choose meaningful measures and judge what the evidence can support.

Record the actual division in CONTRIBUTIONS.md: accepted, changed, rejected, or still uncertain. Do not invent audience feedback, testimonials, approvals, or creative decisions that a person did not make.

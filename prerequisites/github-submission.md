# GitHub version posting — 10 points

[AI Policy for Professor Bear's Courses | Using AI Responsibly in Class](https://youtu.be/8Ut0Cdl6vMw?si=9w3aEpt1ZyAR4Kiz)

Submit the matching version to Canvas and the instructor-designated GitHub repository. Use **fall-2026/first-name-last-initial/assignment-XX/**, for example fall-2026/jane-d/assignment-01/. If names collide, use an instructor-approved suffix. Canvas identifies the repository and reviewer-access workflow; this does not authorize pushing into a shared repository without access.

| Criterion | Points | Evidence |
|---|---:|---|
| Correct location and access | 2 | Reviewer can open the intended semester/student/assignment folder. |
| Complete version | 2 | Required artifact, code, tests, evidence, predictions, contribution record, and Frictional log. |
| Usable README | 2 | Student and Assignment identified; contents, commands, and source credits provided. |
| Identifiable revision | 2 | Intended version committed and pushed; folder URL and final commit hash in Canvas. |
| Matching and appropriate sharing | 2 | Canvas version matches; credentials, restricted data, and private conversations excluded. |
| Total | 10 | |

Per row: 2 complete; 1 partial; 0 absent. These points assess delivery, not effort or implementation quality. A private designated repository with reviewer access can satisfy posting. A local commit alone cannot.

Write commit messages that name the change and what you learned or tested. Example subject: fix: preserve unmatched rows in join audit. An optional body can say: Prediction: expected three matches. Observed: two matches and one dropped ID. Change: added unmatched-key reporting. Evidence: test_missing_partner; FRICTIONAL entry for the date. Contributions: Claude proposed the check; I traced the rows and revised the join contract.

Keep the final commit hash in Canvas, not inside the commit that would contain its own hash. If you revise after verification, identify and resubmit the new checked revision under Canvas rules. Commit volume is not graded. See [submission templates](../templates/README.md).

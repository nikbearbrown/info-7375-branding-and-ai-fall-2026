# NEU prerequisites — Fall 2026

For enrolled INFO 7375 students. Course administration belongs here, outside the book's chapters. Independent readers can use the lessons without NEU submission or media requirements.

1. Confirm Claude Code access through NEU. [Northeastern's Claude portal](https://claude.northeastern.edu/) describes access for active students, faculty, and staff through the institutional account and SSO. Public overview checked 2026-09-06. Claude Code availability is the instructor's course assumption; contact university support through the portal if access differs. Independent readers need their own Claude Code-enabled account. An account does not establish a direct API credit budget.
2. Install Python 3 and confirm that python3 --version works. Use the standard library first. Keep student work in learning-artifacts/ and put only the intended submission in the designated semester location.
3. Read [AI policy](ai-policy.md), [Frictional](frictional.md), [GitHub posting](github-submission.md), and [Relative Quartile](relative-quartile.md).
4. Use the [artifact templates](../templates/README.md). Before the first run, record your prediction. Practice running python3 main.py and python3 -m unittest discover -p 'test_*.py' inside your own artifact directory.
5. Optional: read the [Brutalist explainer guide](brutalist-video.md). Video is not a requirement and has no separate points.

Each graded Assignment is 100 points: 60 implementation, 10 Frictional, 10 GitHub posting, 20 Relative Quartile. Lesson Assessments are ungraded. Canvas supplies actual ten-day deadlines and the section's official policy text.

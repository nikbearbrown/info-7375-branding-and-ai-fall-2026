# Optional NEU assignment explainers

An explainer can help a reviewer understand your work, but it is optional and has no separate points. Written evidence can earn full credit. Brutalist is one possible workflow; use another suitable recording or presentation tool if it serves your explanation better.

The toolkit source is [nikbearbrown/brutalist.art](https://github.com/nikbearbrown/brutalist.art). Keep its checkout separate from this course. Download through GitHub's Code menu or clone the repository, then follow the README in the downloaded version for current setup and commands. Media tools may use a different stack; that does not change the Python course exercises.

Build an explanation around your actual artifact: question and prediction; mechanism; one real run; one check or failure; what changed and what remains uncertain. Show readable outputs and credit sources. Put the course film and its source notes under youtube/ in a uniquely named folder. Label simulations. Do not fabricate a demonstration or student reflection.

The local sibling Prompt Engineering course contains a fuller [Brutalist tutorial](../../info-7375-prompt-engineering-for-generative-ai/prerequisites/brutalist-video.md). It is an optional companion, not a dependency for completing this course. No paid generation or public upload is required.

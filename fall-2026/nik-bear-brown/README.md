# nik-bear-brown

A place for the public work of Nik Bear Brown's examples — INFO 7375 Branding and AI, Fall 2026.

## Executive summary

**What this is.** Professor Bear's worked examples for **INFO 7375 Branding and AI**, Fall 2026 — the assignments done the way students do them, on the same cadence, logged the way students log them. This folder is the submission location the course asks for: `fall-2026/<name>/assignment-XX/`.

**What we are doing now: Assignment 3, the visual identity system.** The assignment asks for design tokens in JSON, a Python generator that renders them as an SVG identity specimen, and a rationale for the direction chosen. Professor Bear's version is being built live in class.

**Why this one matters beyond the grade.** Assignment 2 found a real job posting — [Designer Advocate at Figma](../../assignments/nik-bear-brown/advocate/figma-advocate-roles.md) — and a real gap: *never shipped a design system in Figma with tokens and Dev Mode handoff*. Assignment 3 is that gap, closed in public. The tokens file and specimen here are the first piece of evidence for the advocate portfolio, not a throwaway exercise.

**The running brand.** One brand carries through all ten assignments, as the course requires. Assignment 2's positioning decisions constrain the palette and type chosen here.

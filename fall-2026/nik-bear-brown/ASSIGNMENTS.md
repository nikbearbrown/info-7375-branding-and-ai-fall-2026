# ASSIGNMENTS — where each INFO 7375 Canvas assignment's draft lives

## Executive summary

**What this is.** An index of Professor Bear's answers to every assignment in the Fall 2026 Canvas course (section 05, from the Canvas export of 2026-10-17). One folder per assignment, named after the Canvas assignment title in lower kebab case with the "Assignment N:" prefix dropped.

**Why read it.** Assignments 1–6B already had worked examples in this folder (written 2026-09-26 to 2026-10-11). The remaining ones did not. This index points at both sets, so nothing has to be searched for.

**What it found.** Of the nine folders added with this index, two can be drafted well from records (Assignments 10 and 11, whose stories use only events already on file), and the rest are blocked on things nobody has done yet: trademark and domain lookups, design work, a built website, a recorded pitch. Three items cannot be drafted by anyone but Professor Bear or a student: the Assignment 11 reflection, the guest-speaker questions and the TRACE survey. Every value is labeled **record**, **judgment** (a draft opinion) or **your input** (a typed `[TODO: …]`), and none of these drafts has been reviewed by him.

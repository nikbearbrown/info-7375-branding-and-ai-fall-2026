# Artifact and submission templates

For each lesson, create a working directory in learning-artifacts/. Copy these templates and replace prompts with your own records. A copied blank template is not evidence.

- [PREDICTIONS.md](PREDICTIONS.md): initial expectation and later comparison.
- [FRICTIONAL.md](FRICTIONAL.md): honest effort.
- [CONTRIBUTIONS.md](CONTRIBUTIONS.md): student, AI, and source contributions.
- [VERIFICATION.md](VERIFICATION.md): checks on the shipped candidate.
- [SUBMISSION-README.md](SUBMISSION-README.md): navigation and reproduction.

The implementation language is Python. Record actual run and test commands appropriate to your project. Keep original inputs or explain how an authorized reviewer can retrieve them. Use fixtures when needed and label them. Final graded work uses the instructor-designated fall-2026/student/assignment location.

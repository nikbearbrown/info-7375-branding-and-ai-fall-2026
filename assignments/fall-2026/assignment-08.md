## Predict

Which reassuring sentence in a draft response would overstate what is currently known? Which assumption may fail when the same message reaches a different audience? State the evidence you would need. Save the expectation before the relevant output or feedback.

## Build It

Build a Python incident ledger separating known facts, allegations, unknowns, actions, next update, and authorized spokesperson. Use a fictional incident.

Build a Python localization matrix for invariant claims, adaptable expressions, audience evidence, language, reviewer, and unresolved questions.

## Use It

Ask Claude to draft a holding statement, then update it when a new synthetic fact arrives. Preserve the previous version and identify every changed assertion.

Ask Claude to propose two audience-specific versions of a message. Critique unsupported cultural generalizations and preserve factual claims. If a qualified reviewer participates, record actual feedback; otherwise label review as pending.

## Ship It

Submit incident ledger, two statements, update diff, and decision log; adaptation matrix, two drafts, claim comparison, and review limits. Include the implementation, tests, inputs, actual outputs, source credits, and [submission records](../../templates/README.md). Post the final checked version to the designated GitHub location and upload the matching version to Canvas.

## Verify

Test an allegation presented as confirmed and a promise without an owner. All messages are draft classroom artifacts; do not contact customers or publish a crisis statement.

Test a changed factual promise hidden inside a stylistic adaptation. Language fluency alone does not establish cultural fit. Do not fabricate native-speaker review.

Document actual findings and limitations. Fictional cases, simulations, and proposed campaigns must remain labeled. No ad spend, public release, invented testimonial, or legal clearance is required or implied.

## Division of labor

**AI should** draft and compare statements against the fact record; generate alternatives and compare meaning.

**Human should** judge the response, preserve uncertainty, and authorize real commitments; define the audience, seek appropriate feedback, and decide the limits of the adaptation.

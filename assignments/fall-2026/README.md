# Branding and AI — Fall 2026 Assignments

[AI Policy for Professor Bear's Courses | Using AI Responsibly in Class](https://youtu.be/8Ut0Cdl6vMw?si=9w3aEpt1ZyAR4Kiz)

**Predict → Build It → Use It → Ship It → Verify**

Ten 100-point assignments on a ten-day cadence, advancing one running brand. Canvas supplies actual deadlines and the first due date. Lesson Assessments are ungraded. Use these briefs for Fall 2026 rather than importing older handbook or chapter grading.

| Assignment | Focus | Lessons |
|---|---|---|

| [2](assignment-02.md) | Positioning, architecture, and naming | 3, 4 |
| [3](assignment-03.md) | Visual identity system | 5 |
| [4](assignment-04.md) | Voice and experience | 6, 7 |
| [5](assignment-05.md) | Campaign and content | 8 |
| [6](assignment-06.md) | Measurement and attribution | 9 |
| [7](assignment-07.md) | Governance and claim proof | 10, 11 |

| [10](assignment-10.md) | Verified brand handoff | 15 |

Every Assignment totals 60 implementation + 10 [Frictional](../../prerequisites/frictional.md) + 10 [GitHub posting](../../prerequisites/github-submission.md) + 20 [Relative Quartile](../../prerequisites/relative-quartile.md). Implementation means the specified brand artifact, Python mechanism, application, and evidence; schema completion alone is insufficient.

Use fall-2026/first-name-last-initial/assignment-XX/ in the instructor-designated repository and submit a matching Canvas version with final commit hash. Videos are optional with no separate points. A mock launch can satisfy the final handoff; public deployment, paid ads, and customer outreach are not requirements.
